# ShortP2P.Transport.Abstractions

Контракты транспортного слоя: единый интерфейс `ITransport` для отправки сырых байт и приёма в канал (дальше расшифровка идёт в мессенджере). Зависимостей на конкретные реализации (UDP, Bluetooth и т.д.) здесь нет.

## Структура

| Файл | Назначение |
|------|------------|
| `ITransport.cs` | Интерфейс транспорта (`Start`/`Stop`, `Inbound`, `SendAsync`) |
| `TransportKind.cs` | Вид транспорта |
| `TransportAddress.cs` | Адрес назначения (абстракция) |
| `TransportReceiveMessage.cs` | Входящее сообщение с адресом отправителя |
