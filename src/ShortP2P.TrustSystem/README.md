# ShortP2P.TrustSystem

Репутация **чужих** messenger-серверов: рейтинг 0..1, жалобы абонентов, восстановление.

| Метод | Поведение |
|-------|-----------|
| `AskRating(ip, port)` | Если сервера нет в списке — добавить с рейтингом **0.8**. Вернуть все известные серверы и рейтинги. |
| `AskServers()` | Список серверов с рейтингом ≥ **0.3**. |
| `ClaimServer(ip, port, reason)` | Жалоба на другой сервер (не на себя). `UNAVAILABLE`, `MALFUNCTIONED`, `WRONGCERT`. |

Пороги считаются от числа абонентов **этого** сервера.

- **MALFUNCTIONED / WRONGCERT:** если уникальных жалобщиков **больше 5%** — −0.1; каждый следующий 5%-й шаг умножает рейтинг на 0.5; ниже 0.05 → **0**.
- **UNAVAILABLE:** больше 5% уникальных жалоб за **1 час** — −0.05 (и так до 0).
- **Тишина 1 час** (нет жалоб) — линейное восстановление до **0.8 за 6 часов**.

Хранилище: порт `ITrustStore` (in-memory в библиотеке; LiteDB на API-хосте).
