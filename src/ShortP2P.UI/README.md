# ShortP2P.UI

Заготовка под отдельный UI-слой: сейчас содержит только `UiPlaceholder` — точку расширения для кроссплатформенного UI (например Avalonia или MAUI), связываемого с `ShortP2P.Messenger`.

## Структура

| Файл | Назначение |
|------|------------|
| `UiPlaceholder.cs` | Заглушка/документация в коде |

Зависимости: `ShortP2P.Messenger`, `ShortP2P.Discovery` (для будущей привязки к сценариям обнаружения).
