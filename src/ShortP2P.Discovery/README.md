# ShortP2P.Discovery

Обнаружение пиров в локальной сети по **UDP**: маяки, идентификация, события о найденных узлах. Опирается на типы из `ShortP2P.Transport` (UDP).

## Узел и возможности (capabilities)

**Узел (нода)** — устройство с установленным приложением ShortP2P, выступающее как участник overlay: у него есть сетевой адрес, идентичность в сети и набор **ролей**, которые он готов выполнять.

В **presence / discovery ping** (см. `PresencePingCodec`, `PresencePeerCapabilities` в проекте `ShortP2P.Client`) узел передаёт 16-битную маску заявленных возможностей. Это единый перечень того, «что умеет» нода с точки зрения протокола; остальные подсистемы (мессенджер, ретранслятор, хост приложений) при старте или в настройках должны согласовываться с этой маской.

### Полный список продуктовых ролей

| Роль | Смысл | В wire (`PresencePeerCapabilities`) | По умолчанию в пинге |
|------|--------|-------------------------------------|------------------------|
| **Messaging** | Прямой приём и передача сообщений чата (основной P2P-канал приложения). | `Chat`, бит 0 | Да — клиент **всегда** выставляет этот бит при сборке пинга и при разборе считает Messaging включённым, даже если поле маски отсутствует (legacy). |
| **Discovery** | Поиск и объявление узлов: участие в discovery-слое (LAN, при необходимости другие транспорты), ответ на запросы обнаружения, поддержание списка видимых пиров. | `PeerSearch`, бит 1 | По мере реализации; пока флаг зарезервирован. |
| **Retranslation** | Ретрансляция данных для других узлов (мост/relay), когда прямой путь недоступен. | `Relay`, бит 2 | По мере реализации; пока флаг зарезервирован. |
| **ApplicationHosting** | Хостинг вынесенной логики: приложения, боты, сценарии на стороне узла (не часть базового чата). | `BotHosting`, бит 4 | На будущее; имя члена enum историческое (`BotHosting`). |

### Зарезервировано в маске пинга (вне четырёх ролей выше)

| Бит | Идентификатор в коде | Назначение |
|-----|----------------------|------------|
| 3 | `EncryptedTemporaryStorage` | Зарезервировано под зашифрованное временное хранилище на узле; не входит в текущий продуктовый набор из четырёх ролей. |

При расширении протокола новые биты добавляются только с обновлением `AllDefined` и документации; при приёме неизвестные биты маскируются и игнорируются.

## Структура

| Файл | Назначение |
|------|------------|
| `IPeerDiscoveryService.cs`, `UdpPeerDiscoveryService.cs` | Контракт и реализация сервиса discovery |
| `UdpPeerDiscoveryOptions.cs` | Параметры (порты, таймауты и т.д.) |
| `DiscoveredPeer.cs`, `PeerIdentity.cs` | Модели найденного пира и идентичности |
| `DiscoveryBeaconCodec.cs`, `CompressedNetworkId.cs` | Кодирование маяков и сжатый идентификатор сети |
| `DiscoveryNotifications.cs` | Уведомления о событиях discovery |

Зависимость: `ShortP2P.Transport`.
