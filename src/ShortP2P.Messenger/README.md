# ShortP2P.Messenger

Слой мессенджера поверх **ITransport** и **P2PSession**: шифрование бинарных сообщений, фрагментация под лимит сессии и
сборка входящих фрагментов.

## Структура

| Файл                       | Назначение                                        |
|----------------------------|---------------------------------------------------|
| `MessengerService.cs`      | Основной сервис: отправка/приём, канал `Incoming` |
| `MessengerOptions.cs`      | Настройки                                         |
| `ChunkCodec.cs`            | Кодирование чанков                                |
| `IncomingBinaryMessage.cs` | Входящее сообщение после расшифровки              |

Зависимости: `ShortP2P.Crypto`, `ShortP2P.Transport.Abstractions`.
