# ShortP2P.Crypto

Библиотека криптографии для P2P: генерация RSA-ключей, рукопожатие и шифрование пакетов сессии (`P2PSession`). Целевой
фреймворк — **net8.0** и **net10.0** (Server использует net8, клиентские приложения — net10).

## Структура

| Файл / область                                         | Назначение                          |
|--------------------------------------------------------|-------------------------------------|
| `P2PCrypto.cs`                                         | Фасад: ключи, handshake, шифрование |
| `P2PHandshake.cs`, `P2PHandshakeResult.cs`             | Протокол рукопожатия                |
| `P2PSession.cs`                                        | Сессия с ключами и лимитами пакетов |
| `RsaKeyPair.cs`, `RsaPublicKey.cs`, `RsaPrivateKey.cs` | RSA-ключи                           |
| `CryptoPrimitives.cs`                                  | Низкоуровневые примитивы            |

Исходники лежат в корне проекта (без отдельных подпапок по namespace).
